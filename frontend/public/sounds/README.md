# Sound Effects

Place the following `.mp3` files in this directory to enable sounds:

| File | Description |
|---|---|
| `card_deal.mp3` | Soft card slide — played when hole cards are dealt |
| `community_card.mp3` | Heavier card flip — played when community cards are revealed |
| `chip_bet.mp3` | Single chip clink — played on bet/raise/call |
| `pot_small.mp3` | Few chips clink — played on small pot collection |
| `pot_large.mp3` | Chip cascade — played on large pot collection |
| `your_turn.mp3` | Subtle notification chime — played when it's your turn |
| `fold.mp3` | Card slide away — played on fold |
| `all_in.mp3` | Chip slam — played on all-in |
| `vote_banner.mp3` | Soft alert tone — played when vote banner appears |

If files are missing, sounds are silently skipped. No console errors.
